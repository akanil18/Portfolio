# Anil Paliwal - AI/ML Portfolio Project Plan & Overview

This repository contains the high-performance personal portfolio website for **Anil Paliwal** (AI/ML Developer & Generative AI Engineer).

---

## 🎨 Theme & Architecture Philosophy: Pahadi Vernacular UI
The website is designed using principles derived from traditional **Himalayan Vernacular Architecture** (Uttarakhand & Himachal Pradesh):

1. **Kath-Khuni Wood-Stone Interlock**:
   - Alternating structural card system using modern CSS glassmorphism, Deodar wood amber accents (`#f59e0b`), and slate charcoal backgrounds (`#121820`).
2. **Pathali Sloped Roof Geometry**:
   - Angular section breaks, mountain contours, and sloped hero headers.
3. **Aipan Cultural Artwork Motifs**:
   - Terracotta red accents (`#ea580c`) and crisp ivory typography (`#fff7ed`).
4. **Rendering Performance**:
   - 100% Vanilla HTML5 + CSS3 + JavaScript with zero heavy framework overhead (LCP < 0.8s, CLS = 0).

## 🚀 Running Locally

To run and preview the portfolio on your local machine:

```bash
# Start python local HTTP server
python3 -m http.server 8000
```

Then visit **`http://localhost:8000`** in your browser.
